Data Folder for Bulk Import
==========================

Place PDF files in subfolders here for the "Add Multiple Articles" feature.

Example:
  data/
    batch_2024/        <- Enter "batch_2024" in Admin
      paper1.pdf
      paper2.pdf
    papers/
      jan/             <- Enter "papers/jan" in Admin
        article.pdf

Go to Admin > Add Multiple Articles, enter the folder name, and click Scan.
